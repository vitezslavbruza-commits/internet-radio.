# RadioWave – internetové rádio

Jednoduché responzivní webové rádio pro GitHub Pages.

## Nahrání na GitHub Pages
1. Rozbal ZIP do počítače.
2. Otevři svůj repozitář na GitHubu.
3. Nahraj **obsah rozbalené složky** (ne samotný ZIP) přes **Add file → Upload files**.
4. Potvrď **Commit changes**.
5. V repozitáři otevři **Settings → Pages**.
6. V části Build and deployment vyber **Deploy from a branch**, větev `main` a složku `/(root)`, potom Save.

## Funkce
- Katalog českých a zahraničních stanic z veřejného Radio Browser API
- Vyhledávání stanic
- Filtry: všechny, české, zahraniční a oblíbené
- Ukládání oblíbených stanic v prohlížeči
- Přehrávání, pozastavení, zastavení a hlasitost
- Media Session ovládání na podporovaných zařízeních
- Základní soubory webu se mohou uložit pro offline otevření

**Poznámka:** živé rozhlasové streamy vyžadují internet. Přehrávání při zhasnutém displeji závisí na telefonu, prohlížeči a konkrétním streamu; webová aplikace to nemůže zaručit. Některé stanice mohou přehrávání v prohlížeči blokovat nebo mít dočasně nefunkční stream.
